# 本机启动与 MySQL 联调

这些工具只作用于当前项目，不修改 Windows 的 JAVA_HOME、PATH 或其他 IDEA 项目设置，不重启已有 MySQL 服务。

当前本机已经完成真实 MySQL 联调：主机 localhost，端口 3306，项目数据库 medical_system，四张表和三条科室数据。数据库模式当前访问地址为 <http://localhost:18082/>；18081 用于可单独启动的 demo 模式。应用使用新建的专用账号，后续启动无需输入 root 口令。

首页现已升级为可操作的科室管理页面，详见 [科室管理实验操作步骤](科室管理实验操作步骤.md)。mysql 模式运行在18082；demo 可单独启动于18081，未启动时不会占用端口。

## 1. 启动与构建

在 IDEA Terminal 或 PowerShell 中，切换到项目根目录后执行：

~~~powershell
& .\scripts\Start-Medical.ps1 -Mode demo -Port 18081
~~~

使用本机 IDEA 随附的 JDK 17，打开 <http://localhost:18081/>。脚本先通过项目信息接口识别已运行的医疗系统，识别成功则复用现有实例，不再启动第二份。端口由其他或尚未就绪的服务占用时退出，可换端口；不会结束已有进程。按 Ctrl+C 只停止此次新启动的实例。

IDEA 导入项目后，也可选择预置的 Medical demo (JDK 17, port 18081) 运行配置。它使用独立的 JDK 路径直接运行已经打包的 JAR；启动前先停止同端口实例。

离线构建与测试：

~~~powershell
& .\scripts\Build-Medical.ps1 -Offline
~~~

缓存不全时去掉 -Offline，由 Maven 下载依赖。换电脑时可传入 -JdkHome 和 -MavenHome。构建结束后恢复进程原有 JAVA_HOME，不改变系统配置。

## 2. 首次初始化 MySQL

推荐在资源管理器中双击项目根目录的“配置数据库.cmd”。可见命令窗口会依次询问用户名（回车默认为 root）和口令，口令隐藏显示，无需输入 SQL 指令。配置完成后回到 Codex 验证。

也可以选择图形输入框：

~~~powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\scripts\Initialize-MedicalDatabase.ps1
~~~

Bypass 只对本次进程生效，不修改持久执行策略。脚本在本机打开口令输入窗口，默认连接 localhost:3306；实例端口不同时增加 -DatabasePort 参数。本机已经初始化成功，无需再次运行此步骤。

输入现有管理员账号后：

1. 验证连接；失败时不修改现有账号口令或认证策略。
2. 新建项目数据库；medical_system 已存在时使用带时间及随机后缀的新名称。
3. 只在新库创建四张表和三条科室演示数据。
4. 新建随机应用账号，只授予这四张表的查询、新增、修改、删除权限。
5. 用新账号实际查询，成功后保存本机加密的应用连接配置。

管理员口令不会保存到配置或日志。应用口令使用 Windows DPAPI 加密，存放于 .local/database.xml，只能由当前 Windows 用户在本机解密。.local/ 已加入 Git 忽略列表，源码 ZIP 不包含该目录；换电脑后需重新配置。

多个 MySQL DDL 不能作为整体事务回滚。中途失败时，状态文件报告此次已创建的库或账号；工具不会自动删除它们。已有本机连接配置时会拒绝再次初始化。

## 3. 启动数据库模式

配置成功后，可以直接双击项目根目录的“启动医疗系统.cmd”；它会自动选择 mysql 模式。配置尚未完成时则使用 demo 模式。

双击入口在 mysql 模式使用 18082，在 demo 模式使用 18081，并传入 -OpenBrowser。首次启动会等待项目就绪后打开默认浏览器；重复双击会复用已有医疗系统并打开网页，不再将本项目占用端口显示为错误。浏览器无法自动打开时，会显示可手动访问的 URL。

~~~powershell
& .\scripts\Start-Medical.ps1 -Mode mysql -Port 18082
~~~

自动读取本机加密连接配置，无需在命令行写入口令。验收：

- <http://localhost:18082/api/hello>：中文正常。
- <http://localhost:18082/api/system/database>：connected=true。
- <http://localhost:18082/api/departments>：内科、外科、儿科。

mysql 模式使用 18082，demo 模式使用 18081，可同时运行。若手动将两种模式设置到同一端口，脚本只复用已有实例，不切换其运行模式；需要改变模式时由用户先停止该实例再启动。
